# Nuxt data-fetching playground (learning project, not production)

## Rules

- Look up Nuxt APIs with the Nuxt MCP before using them. Cite the doc page or source file.
- Verify what you can (typecheck, curl the API, server log) and paste the evidence.
  Then list what I should check in DevTools. Never claim it works without evidence.
- Disagree with me when I'm wrong. Point out ambiguity in my prompt before acting on it.
- When compacting, keep: current step, files changed, open questions.
- !important - dont return with a wall of text!!! if there are many important things, divide them into clear section with a headline of sort, so i know if you ask something, return a analyze, conclude or anything else.
